## 💖 About The Project

**Smart Booking App** is a modern frontend web application designed to provide a clean and smooth booking experience.

This project is built using **HTML, CSS, and JavaScript** to strengthen frontend development skills, improve responsive design knowledge, and practice real-world deployment using **Vercel**.
